# wgrender benchmarks

Generated by `tools/benchmarks.py`: do not edit. Baseline measured 2026-09-23 on 13th Gen Intel(R) Core(TM) i9-13900HX, Linux, Brave Browser 153.1.95.104, Emscripten 5.0.7, against wgrender `4d68abd`.

Every binding against the C, on the same example. Each project measures itself (its `tools/benchmarks.py`) with the harness in `tools/bench/`, and this page collects what they recorded.
